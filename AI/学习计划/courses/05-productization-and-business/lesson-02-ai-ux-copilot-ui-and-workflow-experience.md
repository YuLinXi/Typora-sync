# 课时 02：AI 交互设计、Copilot UI 与工作流体验

## 课时定位

- 所属阶段：AI 产品化与商业化阶段
- 建议周期：1 周
- 建议投入：8~10 小时
- 学习优先级：高
- 课时目标：掌握适合 AI Agent 产品的交互模式，设计真正能支撑用户任务完成的 UI 和流程体验。

---

## 学习目标

完成本课时后，你应具备以下能力：

1. 能区分 Chat UI、Copilot UI、Workflow UI 三种模式。
2. 能为不同任务设计最合适的 AI 交互模式。
3. 能设计输入、处理中、确认、结果、纠错和引用的完整体验。
4. 能把 AI 不确定性显式地呈现给用户，而不是假装确定。
5. 能输出一套 AI 产品页面和核心交互原型。

---

## 核心知识点

### 1. 三种常见 AI 交互模式

- Chat UI：适合探索与问答
- Copilot UI：适合嵌入现有工作流
- Workflow UI：适合结构化任务执行与审批

### 2. AI 产品关键界面元素

- 输入区
- 上下文区
- 中间状态展示
- 引用来源
- 工具调用反馈
- 审批与确认按钮
- 失败与重试反馈

### 3. 常见设计原则

- 让用户知道系统正在做什么
- 让用户知道答案依据来自哪里
- 高风险动作必须二次确认
- 结果要可编辑、可修正、可继续

## 课时作业

### 作业题目

为你的 AI Agent 产品设计一套可演示 UI 和关键流程。

### 难度

- ⭐⭐⭐⭐

### 为什么做这个项目

- AI 产品不是把模型输出贴到页面上，而是要让用户完成工作

### Step-by-step 任务拆解

1. 选择交互模式
2. 设计页面流转
3. 设计 AI 执行反馈
4. 设计审批与修正交互
5. 输出原型说明

### 验收标准

- 有完整核心流程，不只是一个聊天框
- 有处理中、成功、失败、确认等状态设计
- 有引用或依据展示
- 有用户可干预入口

### 进阶挑战

- 做移动端适配
- 加入空状态和新手引导
