# 课时 03：SaaS 架构、多租户、计费与权限模型

## 课时定位

- 所属阶段：AI 产品化与商业化阶段
- 建议周期：1 周
- 建议投入：8~10 小时
- 学习优先级：高
- 课时目标：为 AI Agent 产品建立 SaaS 化能力，包括多租户、套餐、配额、权限和账单模型。

---

## 学习目标

完成本课时后，你应具备以下能力：

1. 能为 AI Agent 产品设计多租户数据隔离模型。
2. 能定义套餐、使用量、配额和计费逻辑。
3. 能把权限模型和商业模型结合起来。
4. 能说明 AI 产品成本和价格之间的关系。
5. 能输出一个适合 MVP 上线的 SaaS 基础设计方案。

---

## 核心知识点

### 1. 多租户模型

- 用户
- 团队 / Workspace
- 角色
- 资源归属

### 2. 计费模型

- 订阅制
- 使用量计费
- 混合计费
- 免费额度 + 增值套餐

### 3. 配额设计

- 每月任务数
- Token / Credits
- Agent 数量
- 知识库容量
- 协作席位数

### 4. 权限与商业的关系

- 不同套餐对应不同功能权限
- 高级模型和高级工作流应该有商业分层

---

## 推荐技术栈

- 数据：PostgreSQL
- 计费：Stripe
- 鉴权：Auth.js / Clerk
- 后端：Next.js / Hono

## 课时作业

### 作业题目

为你的 AI Agent 产品输出多租户与计费方案。

### 难度

- ⭐⭐⭐⭐

### 为什么做这个项目

- 产品只要开始面向真实用户，就绕不开权限、套餐和成本控制

### Step-by-step 任务拆解

1. 设计 workspace 数据结构
2. 定义角色和权限
3. 定义套餐和配额
4. 设计收费入口
5. 输出 SaaS 架构图

### 验收标准

- 有明确租户边界
- 有基础套餐设计
- 有配额和权限关联
- 能解释成本和定价逻辑

### 进阶挑战

- 加入团队协作席位模型
- 加入企业版私有化部署选项
