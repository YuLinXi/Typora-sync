## 建议执行方式

1. 每个阶段先读 `README.md`，明确目标和产出物。
2. 再按课时顺序推进，每课都要求有代码、文档或 API 输出物。
3. 每阶段收尾必须完成综合项目，形成作品集。
4. 学习过程中优先以 `Node.js + TypeScript + Next.js` 为主线，不额外切换主战技术栈。
