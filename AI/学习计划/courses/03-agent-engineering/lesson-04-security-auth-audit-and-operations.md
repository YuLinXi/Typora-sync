# 课时 04：安全、权限、审计与生产运维

## 课时定位

- 所属阶段：Agent 工程化阶段
- 建议周期：1 周
- 建议投入：8~10 小时
- 学习优先级：高
- 课时目标：为 Agent 系统建立身份、权限、审计、密钥管理和发布运维的生产边界。

---

## 学习目标

完成本课时后，你应具备以下能力：

1. 能识别 Agent 系统中的权限与数据越权风险。
2. 能设计用户、角色、租户与工具权限的关系。
3. 能建立操作审计日志与关键动作追踪。
4. 能处理密钥、环境变量、第三方凭据的安全管理。
5. 能设计基本的发布、回滚与生产运维流程。

---

## 核心知识点

### 1. 权限模型

- 用户身份
- 角色权限
- 租户隔离
- 工具权限
- 文档访问权限

### 2. 审计日志

- 谁发起了什么任务
- 调用了哪些工具
- 修改了哪些外部系统
- 谁审批了高风险动作

### 3. 密钥管理

- API Key 不落前端
- 最小权限原则
- 环境隔离
- 凭据轮换

### 4. 生产运维

- 发布前检查
- 灰度上线
- 错误告警
- 快速回滚

---

## 课时作业

### 作业题目

为当前 Agent 系统补齐“权限 + 审计 + 发布运维”能力。

### 难度

- ⭐⭐⭐⭐

### 为什么做这个项目

- 真正进入生产环境时，安全和运维经常比模型效果更先决定系统能否上线

### Step-by-step 任务拆解

1. 设计角色与工具权限矩阵
   - 输出物：`permission-matrix.md`
2. 为高风险操作增加审计日志
   - 输出物：`src/audit/audit-log.ts`
3. 设计密钥和配置管理规范
   - 输出物：`secrets-policy.md`
4. 制定发布与回滚流程
   - 输出物：`release-checklist.md`、`rollback-plan.md`
5. 为一个真实场景做权限与审计演示
   - 输出物：`audit-demo.md`

### 验收标准

- 有明确的角色和工具权限边界
- 关键动作可审计可追踪
- 有环境配置和密钥管理规范
- 有上线前检查和回滚说明

### 进阶挑战

- 加入多租户权限隔离
- 为知识库文档增加访问标签
- 接入告警平台做异常通知
