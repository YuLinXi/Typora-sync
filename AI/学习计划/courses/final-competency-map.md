# 最终能力地图

## 完成全部学习路径后，你能独立做什么

- 构建带 Prompt、结构化输出和评测的 AI 应用
- 构建具备 Tool Calling、Memory、RAG、Planning 的单 Agent 系统
- 构建带状态机、日志、评测、追踪和权限控制的 Agent 工程系统
- 构建具备角色分工、共享上下文和 Review 机制的多 Agent 系统
- 构建具备多租户、计费和产品交付能力的 AI Agent SaaS 原型

---

## 能胜任什么岗位

### 1. AI 工程师

- 能负责 LLM 应用开发
- 能接模型、做 RAG、做工具调用
- 能落地中小型 AI 功能

### 2. Agent 工程师

- 能设计和实现单 Agent / 多 Agent 系统
- 能做工作流、记忆、质量控制、可观测性
- 能处理复杂任务自动化

### 3. AI 产品工程师

- 能把 Agent 系统做成面向真实用户的产品
- 能处理 UI、工作流、权限、计费和试点验证

### 4. AI 应用架构师（偏应用层）

- 能做技术选型、系统分层、复杂 Agent 协作设计
- 能推进团队级或平台级 AI 系统建设

---

## 与普通前端工程师的关键差异

| 维度 | 普通前端工程师 | 完成本路径后的你 |
| --- | --- | --- |
| 目标 | 做页面和前后端业务功能 | 做 AI 能力驱动的产品和系统 |
| 数据处理 | 以接口和状态管理为主 | 还要处理 Prompt、上下文、检索、记忆 |
| 交互设计 | 关注页面可用性 | 还要设计 AI 工作流、反馈和不确定性呈现 |
| 后端能力 | API、数据库、业务逻辑 | 再加 Tool Calling、Workflow、队列、可观测性 |
| 系统设计 | 组件和服务架构 | 再加 Agent 架构、多 Agent 协作和质量治理 |
| 商业理解 | 功能交付为主 | 还要考虑 SaaS、计费、试点和产品验证 |

---
