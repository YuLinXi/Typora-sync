# 第一阶段：基础认知阶段

## 阶段定位

- 阶段名称：基础认知阶段（AI + LLM + Prompt）
- 建议周期：4~6 周
- 学习优先级：高
- 阶段目标：从传统前端工程思维过渡到 AI 应用工程思维，建立 Prompt、模型调用、结构化输出、RAG 和基础评测能力。

---

## 阶段学习目标

完成本阶段后，你应具备以下能力：

1. 理解 LLM 应用的最小工程结构，而不是只停留在聊天式使用。
2. 能用 TypeScript 调用模型 API，并实现结构化输出与解析。
3. 能为固定任务设计可复用 Prompt 模板。
4. 能实现一个最小 RAG 系统，为知识型 AI 应用提供外部上下文。
5. 能对模型输出进行基础评测、调试、成本控制和风险分析。

---

## 阶段课时安排

| 课时 | 标题 | 重点 | 建议投入 |
| --- | --- | --- | --- |
| 01 | LLM 基础认知与结构化 Prompt 工程 | Prompt 设计、输出契约、Prompt Lab | 6~8 小时 |
| 02 | 模型 API 调用、结构化输出与结果解析 | SDK、JSON 输出、Schema 校验、容错 | 6~10 小时 |
| 03 | Embeddings、上下文工程与 Mini RAG 入门 | 文档切分、检索、上下文拼接、引用回答 | 8~10 小时 |
| 04 | 模型评测、调试、成本控制与安全边界 | Evals、日志、重试、限流、风险控制 | 6~8 小时 |
| 05 | 阶段综合项目：AI 文档助手 MVP | Prompt + API + RAG + Eval 作品集项目 | 10~14 小时 |

---

## 推荐学习顺序

1. 先完成 01 和 02，建立稳定输入输出契约。
2. 再完成 03，把模型接到外部知识。
3. 然后完成 04，建立评测与工程稳定性意识。
4. 最后完成 05，把前四课时的能力整合成一个 Portfolio 级项目。

---

## 阶段可交付成果

- 一个可复用 Prompt 模板库
- 一个结构化输出 API 示例
- 一个最小 RAG 知识问答系统
- 一套基础评测与调试方法
- 一个可演示的 AI 文档助手 MVP
